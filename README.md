# 🖥️ System Health Monitor

A bash script that monitors and displays real-time system health 
including CPU, RAM, Disk usage, and top processes.

## 🚀 How to Use
\```bash
# Clone the repo
git clone https://github.com/nikk-nagar/system-health-monitor

# Give permission
chmod +x monitor.sh

# Run it
./monitor.sh
\```

## 🛠️ Technologies Used
- Bash Scripting
- Linux Commands: top, free, df, ps

## 📌 What it monitors
- ✅ CPU usage %
- ✅ RAM used vs total
- ✅ Disk usage per partition
- ✅ Top 5 CPU-consuming processes
